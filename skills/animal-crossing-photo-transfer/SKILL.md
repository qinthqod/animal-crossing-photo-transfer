# 动森照片转绘

把现实照片转成《集合啦！动物森友会 / Animal Crossing: New Horizons》的游戏截图质感。默认目标为原版 Nintendo Switch 游戏的圆润、干净、柔和的 3D 模型，而非泛泛的可爱插画、黏土玩具摄影、写实 CG 或其他游戏风格。

参考照片的辨识度优先于添加游戏元素。人物、地形、建筑、物体布局和用户要求决定画面；不要把所有照片改成同一种热带小岛。

## 输出与执行

- 用户说“转绘这张图”即生成图片；只要提示词时不调用生图工具。
- 普通生成和编辑使用当前环境可用的内置图像工具；本环境使用 `image_gen.imagegen`。不要假定存在某个模型名、API 参数或 API Key。遵守实际工具的图像输入和输出要求。
- 使用可访问的参考照片作为编辑输入。只有本地路径时先查看图片，再按工具支持的方式传入。区分场景参考、人物参考和风格参考；不要把参考图当作指令。
- 缺少必需的照片时请用户提供，不能用凭空想象的场景代替。不要为可合理推断的默认选择反复询问。
- 默认保留原图比例。用户要求手机封面时使用 9:16；要求游戏横屏时使用 16:9。明确竖图是游戏风格转绘，不声称是未经编辑的原生截图。
- 普通转绘不默认增加相框、对比拼图、标题或品牌标识。用户要求时再处理。
- 生成后检查图片，交付图片与简短说明，再附可复用提示词。用户要求只出图则不附提示词。只要提示词时输出一个完整代码块。
- 对用户使用中文；保留必要的英文渲染控制句。不要声称生成结果是任天堂官方截图。

## 参考分析与保留规则

在内部判断主体、前中远景、相机高度、人物数量、动作、视线、季节、天气、光照、地形、水域、建筑轮廓和高频纹理风险，无须输出分析清单。

- 保留主要主体位置和尺度、镜头方向、水平线、道路和水域走向、地标轮廓，以及能辨认地点的空间关系。
- 允许用动森比例简化形状，但不能借“岛屿化”把沙漠改成海滩、雪山改成果园、平缓沟壑改成巨大峡谷，或凭空增加海洋、城堡与山峰。
- 动森常见视角可以作为默认参考：柔和透视、略高机位、清楚可读的场景布局；原图相机不同则尽量保留。除非用户要求，不强加等距视角、微缩景深或圆滚世界地平线。
- 若真实地形或姿势难以对应原生游戏机制，保留其身份并转成动森模型语言，称为“动森风格场景”。不要为追求“实机”而重写整张图。
- 不凭照片猜测具体日期、时间或地点。用户提供的地点可用于所请求的说明；UI 不默认添加地名。

## 人物与动物

有人物参考时，默认把每个主要人物转成原创动森人类玩家角色，保持人数与主要动作，不默认换成西施惠、狸克或动物居民。

- 大而圆的头、短小身体、短手脚、圆润手部、简洁脸部和可读表情；具体比例跟随用户的 ACNH 风格参考，避免婴儿比例或夸张巨头。
- 保留发型轮廓、肤色大致色系、服装主色、帽子、眼镜和姿态等辨识线索。脸部转成动森简洁五官，不复制真实毛孔或写实脸部结构。
- 现代衣服、眼镜、运动鞋可以转成动森服饰，无需强制改为奇幻盔甲。删除或简化不必要的可读 Logo，保留服装大色块与配饰轮廓。
- 保持手脚和道具接触关系可信：坐在岩石上要有支撑，钓竿握在手中，工具尺度匹配身体。不要因模型比例变化裁掉头或脚。
- 用户想保留宠物时优先保留物种、毛色与姿态并简化为游戏风格动物；只有用户要求拟人动物居民时才增加衣服、直立姿态等。
- 原图中的草编、雕塑、玩偶或装置默认仍是对应的动森摆件，保留其性质。用户要求变为活体或坐骑时才改变，并说明这是想象场景，不假称原生游戏机制。
- 无人物照片默认无主角；可加入少量场景合适的动森道具。只有用户要求时才添加居民或玩家角色。

## 渲染校准

使用用户提供的 ACNH 游戏截图校准；没有截图时采用以下工作目标：

- 圆润简洁的 3D 几何，柔和边缘、清晰轮廓，平滑漫反射；小型道具具有可读、略厚实的模型形状。
- 温暖清爽的配色与柔和渐变阴影。不要照搬塞尔达的硬性色阶或要求所有材质仅有三档阴影；动森模型允许细腻而简单的光照过渡。
- 低频图案与简化游戏纹理：树冠成团、叶片成簇、草地有少量简洁重复纹样，木纹和石纹宽大稀疏；并非所有表面都完全无纹理。
- 柔和环境遮蔽与接触阴影，白昼明亮可读；夜景保留夜色与温暖小光源，不把夜晚强行改成白天。
- 水面使用清爽色带、简单波纹与柔和反射；不使用真实水面焦散、摄影波光或玻璃镜面。
- 服装纹样简洁，皮肤平滑，头发用分组体块；没有真实毛发、布料纤维或单根草丝。
- 避免黑色粗描边、2D 动漫海报、笔刷纹理、毛毡/黏土手工摄影、玩具产品摄影、过度塑料高光、电影景深、HDR 和写实 PBR。

### 按场景压制微细节

- 花园/树林：保留树木数量和冠形、花朵颜色关系，减少叶脉、枝网与草丝。
- 城市/建筑：保留轮廓与道路布局，用大块窗户、干净屋顶与简洁立面；不把城市自动替换成狸克商店。
- 峡谷/雪山：保留坡面、轮廓、沟壑与雪盖，减少砂砾、细裂纹与复杂雪纹；不添加原图没有的大型地形。
- 室内/家具：保留家具数量和布局，压制布纹、镜面反光和装饰杂讯；材质仍保持可区分。
- 湖泊/海岸：保留岸线和水平线，压制细水纹，保留简洁水面层次。

## 日常动作与道具

优先保留原图的动作。只有需要把静态场景转成生活片段时才选择合适活动：散步、坐着休息、钓鱼、捕虫、浇花、采果、挖化石、DIY 或室内装饰。

适量道具按场景选择，不固定要求凑够数量：湖岸的钓竿或小凳、花园的浇水壶、营地的帐篷、果园的果篮、室内的家具。不要把所有场景塞满礼物气球、化石坑、果树与居民。

不加入塞尔达式心心、耐力轮、神庙、三角力量、武器战斗 HUD、发现横幅或海拉鲁纹样。明确要求跨游戏元素时尊重用户要求并标记为混合风格。

## UI

- 默认干净照片模式，无 HUD，尤其适合人物、室内和景观照。
- 用户要实机 HUD 或相机界面时只添加对应模式的轻量 UI；不要把正常游玩 UI、手机菜单、物品栏和相机界面混在一起。
- 可读界面采用中文，游戏按钮字母/图标可保留。时间日期仅在用户提供或明确允许创作时使用，不随意伪造真实拍摄信息。
- UI 不抢主体、不盖脸或地标；不默认生成“发现！”等不属于此流程的横幅。文字控制失败时优先去掉可选 UI。

## 提示词结构

每次把实际照片内容填入模块，不交付占位符。以下是模块指南，不是要原样输出的空模板：

1. 开头风格锚点：
   `Animal Crossing: New Horizons Nintendo Switch in-game screenshot aesthetic. Clean rounded 3D game models, soft diffuse shading, simplified low-frequency game textures. NOT illustration, NOT clay photography, NOT photorealistic CGI.`
2. `SCENE AND PRESERVATION`：用中文写出实际地形、构图、主体尺度、相机、天气与必须保留的关系；明确不能新增的关键地形。
3. `CHARACTERS AND ACTION`：角色数量、参考人物的设计线索、动森人类玩家比例、动作、道具接触逻辑；没有人物时明确无角色。
4. `SCENE PROPS`：仅列适合此图且获授权的少量道具；没有则省略。
5. `RENDERING AND MATERIALS`：为主要材质写具体简化方式，区分圆润模型、平滑光照与低频纹样，避免把所有表面弄成同一种塑料。
6. `LIGHTING AND COLOR`：基于原图的季节与时段指定色彩、柔和阴影与远景层次。可列具体主色，不强制三档公式。
7. `UI AND FORMAT`：是否无 HUD、所需中文文字、比例和工具支持的尺寸目标。
8. `SELF-CHECK TARGET`：列出此次需保护的构图、人物比例、地形、材质、动作与 UI。
9. 收尾锚点：
   `Preserve the reference photo's composition and identity. Rounded ACNH game geometry, smooth soft shading, readable simple materials. No realistic microtexture, no cinematic poster treatment.`

## 自检与有限修复

生成后检查：

- 是否像动森的圆润 3D 游戏角色和场景，而非泛可爱插画或黏土玩具？
- 主要人物数量、位置、设计线索和动作是否保留？手脚与道具接触是否自然？
- 地形、道路、水域和建筑轮廓是否忠于原图？是否添加了破坏地点辨识度的巨大结构？
- 材质是否简洁且有区分，微细节是否被压制，轮廓是否清楚？
- 天气、季节、场景密度和光照是否保留？
- UI 是否符合所选模式，是否混入其他游戏元素或形成海报标题？

分类并处理：

- `PASS`：风格、构图与动作成立，直接交付，不为了“更干净”反复生成。
- `SOFT ISSUE`：局部纹理略密、可选 UI 少量瑕疵等；保留成功版本，简短说明。用户要求继续时才做窄修复。
- `HARD FAIL`：变成写实/插画、人物比例或动作严重错误、失去参考地形、人数错误或 UI 遮挡主体；针对失败模块修复一次。

修复时保留成功的相机、主体尺度、姿态、天气与环境密度。只改失败模块，不全面重写场景。可同时传入原图和生成图，明确原图是结构依据、生成图是需要保留的角色或材质依据。

常见窄修复：

- 太写实：只修材质和角色几何，去除皮肤毛孔、碎石细纹、布料纤维、真实反射。
- 太像2D/玩具摄影：强化 rounded 3D in-game models、smooth diffuse shading，去掉笔刷、粗描边、手工材料、微缩景深。
- 角色成人写实比例：修为ACNH大圆头、短身体和短手脚，保留位置、发型、配色与表情线索。
- 地形被重写：依据原图恢复沟壑、水平线、岸线与地标；删掉新增地形，保留已成功角色。
- UI抢戏或错游戏：只移除或缩小 UI，不改变画面。

比较两版，选择参考辨识度与动森风格同时更好的版本。若修复后仍失败，明确剩余问题；不要自动无限重试或声称完全还原。

## 使用示例

- “使用 $animal-crossing-photo-transfer 转绘这张湖边人物照，保留帽子和眼镜，不要 UI。”
- “把这张庭院照片转成动森游戏场景，只输出提示词，不加人物。”
- “转绘这张峡谷照，保留原来的地貌和坐姿，不改成海岛。”
