# 测试与调用示例

以下请求需与相应的参考照片一起使用。实际提示词必须分析用户的照片，不能照搬示例地形或人物。

## 湖岸人物与摆件

请求：

```text
使用 $animal-crossing-photo-transfer 转绘这张湖岸照片。
保留雪山、蓝湖、大片天空、人物宽檐帽，以及人物坐在草编动物雕塑上的构图。
雕塑仍是摆件，不改成活体坐骑。不加 HUD。
```

检查：人物为原创动森人类玩家，头身比例正确；帽子与服饰色系保留；摆件材质简化；湖岸与山体关系不变；没有多余人物或房屋。

## 峡谷坐姿人物

请求：

```text
使用 $animal-crossing-photo-transfer 转绘这张峡谷人物照片。
保留蓝色墨镜、浅灰服装、坐在岩石上回望的姿态与高机位。
保留远处平缓荒漠和浅层分叉沟壑，不添加城堡、巨大台地或海洋。
```

检查：手与岩面接触自然；头脚完整；人物不是成人写实比例；荒漠仍可辨认；衣服没有变成奇幻盔甲。

## 仅修改 HUD

请求：

```text
给刚才的转绘图加轻量动森游玩 HUD，保持人物、姿态、构图与颜色。
左下角放示例时间 10:30 与「周五」，右下角放小地图和位置标记。
这些是虚构游戏时间与示意地图，不代表真实拍摄信息。
不要加相机边框、物品栏、对话框或其他游戏的心心与耐力轮。
```

检查：UI 不遮脸、手脚或主要物体；文字清楚；不同 UI 模式没有混用；原图内容没有明显重绘变化。

## 纯风景提示词

请求：

```text
根据这张庭院照片，只输出一个完整动森风格转绘提示词。
保留家具数量、道路与植物布局，不添加人物，保持原图比例。
```

检查：不调用生图工具；输出没有占位符；家具布局保留；材质有区分，不是统一塑料或黏土效果。
